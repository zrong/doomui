# Figma Sync Sandbox

Cocos Creator 3.8.6 最小验收工程。在仓库根执行 `just install`、`just check`、`just sandbox-link`，再用 Creator 打开本目录。

通过 `扩展 → DoomUI → Figma Sync` 打开面板，用短期配对码连接 Figma Desktop 的 Cocos Sync，然后手动 Push；Preview 不写资产，Apply 需明确执行。

验收步骤及证据边界见 [开发指南](../docs/development.md) 和 [验收记录](../docs/acceptance.md)。本机配对信息、生成资产、Profile 与宿主缓存不提交。
