# Cocos Sync

Figma Desktop 伴生插件，用于手动推送明确选择的 Frame / Page 直属 Component，以及一次性导入 Cocos Prefab 和共享素材。

在仓库根运行 `just install`、`just check`，然后在 Figma Desktop 通过 `Plugins → Development → Import plugin from manifest` 导入本目录的 `manifest.json`。使用其中已提交的稳定 plugin ID。

完整配对与操作步骤见 [开发指南](../docs/development.md)，通讯约定见 [本机协议](../docs/local-push-protocol.md)。
